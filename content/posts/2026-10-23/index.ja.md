# 10月23日 · 今日のテック厳選10本

## 本日のサマリー

今日は、サービスの境界を誰がどのように守るかが中心です。DNS の提供地域、エージェントの実行権限、LLM が支援する形式検証まで、便利さを本番に持ち込む前の設計が問われています。

## Picks

### 1. Quad9 がフランスでのサービスを終了へ [HN]

[発表を読む](https://quad9.net/news/blog/au-revoir-france/)

パブリック DNS リゾルバの Quad9 が法的環境を理由にフランスから撤退すると発表しました。DNS は普段意識されにくいものの、事業地域、ログ方針、障害時の切り替えを含む依存先です。海外向けサービスでは、単一のパブリックリゾルバに暗黙に依存していないか確認したいところです。

### 2. OpenShell、自治エージェント群のための実行環境 [HN]

[プロジェクトを見る](https://github.com/NVIDIA/OpenShell)

NVIDIA の OpenShell は、複数の自治エージェントを安全かつプライベートに動かすランタイムを掲げます。採用時には、権限、ネットワーク出口、隔離、監査ログが一体で確認できるかが重要です。エージェントの成功デモより、失敗時に止めて人が引き継げる設計を先に見ましょう。

### 3. Cloudflare のセキュリティ監査 skill [GitHub Trending]

[リポジトリを見る](https://github.com/cloudflare/security-audit-skill)

Cloudflare はコーディングエージェント向けの多段階セキュリティ監査 skill を公開しました。機械可読な検出結果は、チケット化、再現、レビューの流れに乗って初めて価値になります。日本企業の開発プロセスでも、AI の結論だけを残すのではなく、根拠と例外承認を追える形にしたいです。

### 4. Arc ブラウザ、12月22日に終了予定 [V2EX]

[議論を読む](https://www.v2ex.com/t/1251107)

Arc が 12 月 22 日に終了予定という話題です。ブラウザ移行では拡張機能だけでなく、スペース、ブックマーク、認証状態、個人の作業手順まで影響します。利用終了の告知を機に、日常業務が特定の UI に埋め込まれていないか棚卸しする良い機会になります。

### 5. 「プログラマは若い仕事か」をめぐる議論 [V2EX]

[議論を読む](https://www.v2ex.com/t/1251106)

プログラミングを単なる作業として扱うことへの問題提起です。AI 支援が広がるほど、反復実装の価値だけでなく、要件の切り分け、検証、運用上の判断が差になります。経験を暗黙知のままにせず、レビュー観点や設計原則として共有することが有効でしょう。

### 6. PHP 脆弱性ニュース時の初動フローチャート [Zenn]

[記事を読む](https://zenn.dev/mimi/articles/0a158119a3b501)

PHP の脆弱性情報を見た保守担当者が最初に行う判断を整理した記事です。重要なのは設定変更を急ぐことより、対象バージョン、公開経路、保守窓口を先に把握することです。複数ベンダーや古いミドルウェアが混在する環境ほど、影響範囲の表が役立ちます。

### 7. Rootless Docker と SELinux を学ぶ [Zenn]

[記事を読む](https://zenn.dev/nexryai/articles/afb828d7dda6b7)

Rootless Docker を題材に SELinux を解説する入門記事です。コンテナの権限を絞ると、ユーザー名前空間、ボリューム、ネットワーク、ホストポリシーが相互に効いてきます。動かないからといって例外を広げる前に、拒否ログから境界の意味を読み解くのが近道です。

### 8. LLM が形式的ソフトウェア検証を拡張する可能性 [Anthropic]

[研究を読む](https://www.anthropic.com/research/formal-verification)

Anthropic は、LLM を使って形式検証をより大きな規模へ広げる取り組みを報告しています。ここでの安全性はモデルの自信ではなく、証明器や検証器が最終判定をする点にあります。高い保証が必要なコードでは、パッチ生成よりも検証可能な候補を作る用途から検討しやすいでしょう。

### 9. Agent skills を Agentic AI Foundation へ寄贈 [Anthropic]

[発表を読む](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

Anthropic は agent skills を Agentic AI Foundation に寄贈すると発表しました。記述形式やテストが標準化すれば、社内ワークフローを特定の製品に固定しない選択肢になります。ただし移植性と安全性は別問題であり、ツール権限とデータ送信先を明示する運用が必要です。

### 10. Cyber Verification Program を拡大 [Anthropic]

[発表を読む](https://www.anthropic.com/news/cyber-verification-program)

Anthropic は適格なセキュリティ専門家向けの Cyber Verification Program を拡大しました。高度な検証能力を使える範囲が広がるほど、承認済みの対象、実施時間、証跡を明確にする必要があります。強力なテスト手段は、所有者の同意とセットで初めて防御に寄与します。
